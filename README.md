# WoW Forever leveling helper

Gnome Frost Mage route (Part 4, Lv 21-26) with live "right now" steps from the **ForeverGuide** addon.

- `index.html` is the web helper
- `addon/ForeverGuide/` is the in-game addon (`/fg` makes a sync code). `addon/ForeverGuide.zip` is the download
- `archeage/` is the old ArcheAge Classic site, parked for later
